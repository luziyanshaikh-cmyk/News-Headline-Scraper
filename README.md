
# News Headline Scraper

## Objective
A Python application that automatically extracts news headlines from a public news website.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- VS Code

## Features
- Fetches HTML content from a news website.
- Extracts news headlines.
- Displays headlines in the terminal.
- Saves headlines in a text file.

## Installation
Install the required libraries:

pip install requests beautifulsoup4

## How to Run
Run the following command:

python news_scraper.py

## Output
The extracted news headlines are saved in headlines.txt.

## Conclusion
This project demonstrates web scraping, HTML parsing, Python libraries and file handling.
